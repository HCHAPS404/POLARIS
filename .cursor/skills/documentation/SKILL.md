# Skill: documentation

## Purpose

Contract READMEs, ADRs, manuals.

## When to invoke

Root README family, docs/**, CHANGELOG.

## Inputs

Audience, evidence state.

## Workflow

1. Complete files, not stubs, for contract docs. 2. Link ADRs. 3. Changelog Unreleased.

## Outputs

Markdown paths.

## Validation

Links resolve inside the repo.

## Forbidden shortcuts

Pasting entire READMEs into Cursor rules.

## Relevant paths

README.md, README_ARCHITECTURE.md, docs/
